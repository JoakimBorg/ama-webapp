# AMA Web App

The frontend for a user study about the Artificial Moral Assistant. The app currently provides a preview with example scenarios; answers exist only in memory and are not saved or submitted. Do not use the preview to collect study responses.

## Survey preview

The flow contains a welcome page, one page per scenario, and an end page. Participants progress forward without an option to return to earlier scenarios. The end page offers a fresh start; starting over, refreshing, or leaving the page clears the in-memory answers.

Example scenarios are defined in `src/scenarios.js`. Each has a stable `id`, description, yes/no question, and preset example recommendation consisting of a yes/no decision and a short rationale. The complete AMA response writes on, with its recommendation in bold. The first question and AMA panel appear after short pauses; the AMA panel animates into view. Scenario numbers and the total are determined by their order in the list. Each scenario locks and visually marks the initial answer, then locks the second answer briefly before fading to the next scenario. Replace the examples with approved study content before launch; the recommendation is not generated by an AI.

On narrow screens, the Yes/No choices sit side by side, with compact scenario spacing to keep the study content on screen.

The write-on effect respects the participant's reduced-motion preference, presenting the full text immediately when reduced motion is enabled.

Response storage and submission are not implemented. Before collecting data, decide on the storage approach and confirm participant information, anonymity, retention, withdrawal, and any consent requirements.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check the code.

## GitHub Pages

The site is configured for the repository URL path and deploys from the `main` branch using GitHub Actions. Each push to `main` builds the Vite app and publishes it to GitHub Pages.

After the deployment workflow completes successfully, the site is available at:

<https://joakimborg.github.io/ama-webapp/>
