# AMA Web App

The frontend for an anonymous user study about the Artificial Moral Assistant. The current app is a welcome screen; the survey flow and response storage are not implemented yet.

## Development

```sh
npm install
npm run dev
```

Run `npm run build` to create a production build and `npm run lint` to check the code.

## GitHub Pages

The site is configured for the repository URL path and deploys from the `main` branch using GitHub Actions. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

After the workflow completes, the site will be available at:

<https://joakimborg.github.io/ama-webapp/>
